# Portfolios La Plata — Esencial 2

Este repositorio pertenece a Portfolios La Plata.

Es un modelo reutilizable del producto Esencial.

Principios:

- React + Vite + Tailwind.
- One-page.
- Mobile-first.
- Sin backend.
- Sin CMS.
- Sin Analytics.
- Sin funcionalidades del producto Profesional.
- Todo el contenido del cliente debe provenir de src/data/portfolio.js.
- Evitar textos personales hardcodeados en componentes.
- Las secciones vacías deben ocultarse correctamente.
- Los colores deben centralizarse.
- Mantener compatibilidad conceptual con el esquema de Esencial 1.
- Priorizar reutilización, accesibilidad y rendimiento.
- Ejecutar lint y build después de cambios importantes.

Dirección visual:
sobria, minimalista, estructurada y profesional.

No convertir este modelo en una estética creativa/editorial similar a Esencial 1.
